# Diseño de Lumen Mobile

## Archivo de referencia

[Aplicación móvil - Lumen.figcraft](Aplicación%20móvil%20-%20Lumen.figcraft) es el archivo de diseño móvil incluido con el código. Contiene las páginas `Screens` y `Components` y se guarda en formato `figcraft` v1.

El archivo se versiona como un artefacto binario de referencia. No es un diff de interfaz ni ofrece coedición a través de Git. Para actualizarlo, trabaja en una rama dedicada, reemplaza el archivo completo y adjunta al pull request capturas exportadas de las pantallas afectadas. Evita que dos ramas editen el artefacto a la vez.

## Uso durante el desarrollo

- Identifica en el issue la pantalla, estado y tamaño de dispositivo que se van a cambiar.
- Usa el archivo como referencia de diseño; confirma en el PR cualquier diferencia intencional entre el diseño y el comportamiento implementado.
- Si la herramienta de diseño mantiene una versión compartida en línea, añade aquí su URL y permisos de acceso para que las personas colaboradoras puedan editarla en conjunto. El archivo del repositorio, por sí solo, no comparte una sesión en línea.
- No incluyas datos de una biblioteca personal en capturas o exportaciones. Usa contenido ficticio.
